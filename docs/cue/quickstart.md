# Quick Start

1. Generate TLS certificates for the cluster
2. Create a configuration file for each node
3. Start at least 3 nodes
4. Verify the cluster is healthy

## Example

```bash
./cue serve -config config-node1.yml
```

Full configuration examples and multi-node startup scripts are available in the [Cue repository](https://github.com/m-javani/cue).
